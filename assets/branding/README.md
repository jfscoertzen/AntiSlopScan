# antislopscan brand asset

The software intelligence background and supporting inspection illustration have
separate exact Imagegen prompts and provenance in
[`intelligence/README.md`](intelligence/README.md). The original brand mark and its
generation record below remain unchanged.

`antislopscan-mark.png` is the original transparent raster mark used by the Vue
workbench, favicon, standalone HTML, and PDF masthead. Generated on 2026-11-06
with the built-in Imagegen tool, then copied into this repository. It is covered
by the project's Apache-2.0 distribution. The wordmark is selectable system text.
The PNG is embedded in HTML reports, so offline copies need no companion assets.

## Final generation prompt

```text
Use case: logo-brand
Asset type: production app icon and report brand mark for antislopscan, an open-source source-code audit appliance.
Primary request: Create one distinctive, compact symbol that suggests source-code inspection and separating signal from noise: two sturdy opposing code brackets forming a focused aperture, with three short inspection scan bars passing through its center. Deliberate, precise geometry, strong silhouette, crisp flat edges, suitable at favicon size, professional engineering instrumentation character.
Composition: one centered symbol only, generous transparent padding, square canvas. The mark should occupy about 75% of the canvas.
Color palette: deep forest green #164B3D and warm copper #C16A3C on genuinely transparent background. No text, no wordmark, no letters, no shield, no checkmark, no robot, no sparkles, no gradients, no shadows, no 3D mockup, no watermark. Clean vector-like raster artwork, restrained but memorable.
```
