# AntiSlopScan software intelligence design

Reading this as: a software intelligence workspace for developers and reviewers,
with an instrument-panel visual language, dial ENERGY 2 / RHYTHM 2 / MOTION 2.
The supplied cybersecurity references set polish and depth, not a layout to copy.

## Decisions and purpose

- Publication reports share the application palette, original SVG icons and
  conceptual artwork. A score-led cover with restrained topology establishes
  identity; white print pages, clear chapter heads, repeating table headers and
  restrained severity marks support long-form investigation. Static illustrations
  explain four principle families once, followed by evidence-led assessment rows.
  Static and LLM conclusions stay separate within each principle. Report motion is
  zero; HTML retains keyboard-friendly filters and both appearance modes. Machine
  JSON/SARIF remain data exports with no decorative branding payloads.

- Principle review uses compact evidence rows with explanatory conceptual artwork,
  an explicit static/LLM distinction, and a separately labeled sample-based LLM
  architecture score. Illustrative GIFs explain the principle rather than claim
  discovered project behavior; static posters support reduced motion and pause.

- Deep charcoal, graphite, and navy separate shell, working surfaces, and evidence
  without a green cast. Light mode uses the same hierarchy on cool white surfaces.
- Teal is the fresh-install accent; existing saved accent and appearance choices
  remain authoritative. Every named accent has accessible light/dark variants.
- Red and amber classify finding severity independently of the selected accent;
  quality gauges always say higher is better and never imply a passing CI gate.
- System sans provides crisp offline typography. Tabular numerals align measured
  values; monospace is reserved for source locations and machine-readable content.
- A compact navigation/history rail keeps investigation destinations available;
  an expandable assessment panel exposes existing inputs without competing with
  the selected repository. The configuration and API contracts are unchanged.
- The large circular quality gauge anchors the hero; the CI decision is equally
  explicit in text and a semantic icon. Coverage and findings use actual totals.
- Subtle Imagegen topology artwork extends behind the hero and metric row as a
  signature of inspecting connected systems. It is clearly illustrative and is
  never presented as a discovered dependency graph or a measured chart.
- A sparse CSS/SVG flow accent reinforces that illustrative scanning identity.
  It pauses on request and in hidden tabs, and respects reduced-motion settings.
- Gradients are confined to the hero's depth/illumination and selected surfaces;
  opaque content surfaces preserve text contrast. No full-screen glass or neon.
- Original 24px SVG icons consistently identify files, scans, coverage, security,
  architecture, systems, settings, and exports. Icons accompany readable labels.
- Native SVG severity/category charts encode exact canonical values; interactive
  legends and visible values make color supplementary. No trends are fabricated.
- The Architecture network draws only resolved edges and bounded real modules.
  Its radial placement is organizational, not inferred layering or causality.
- Eight/twelve/sixteen-pixel radius steps distinguish controls, panels, and hero;
  border/shadow changes communicate focus, selection, and interactive elevation.
- Findings remain native disclosures, with separate evidence/remediation blocks,
  provenance, safe issue references, and copy actions with visible feedback.
- Loading, empty, execution-error, and no-match states remain explicit; skeletons
  are marked as loading placeholders rather than fabricated product content.

## Verification and provenance

Maintain contrast across every preset and mode, keyboard reachability, 320px to
wide layouts, real audit workflows and downloads, and SVG graph evidence limits.
Background motion is optional and does not carry information. Reports retain
canonical data and their publication layout. Graphic prompts and generated asset
provenance are maintained in `assets/branding/README.md` and
`assets/branding/intelligence/README.md`.
